# JZB Apps branding

The PNG masters are the approved JZB Apps assets from the website: the blue JZB
monogram and the full monogram plus black lowercase `apps` lockup. Do not redraw
the mark or add another `jzb` wordmark.

`jzb-apps.ico` contains 16, 24, 32, 48, 64, 128, and 256 pixel PNG icon frames
exported from the monogram with transparent outer margins trimmed. Wizard artwork
uses these same masters. The large panel is 328 by 628 pixels; the square header
is 176 by 176 pixels. These committed assets require no image-generation or Node
dependency to compile the installer.

The icon and publisher text are branding metadata, not a code-signing identity.
