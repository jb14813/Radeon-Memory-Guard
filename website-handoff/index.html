Legacy workarounds for identified Radeon memory and cache-write issues. The verified Adrenalin 26.11.2 build (driver 32.0.32029.2010) includes native fixes and does not need them.

Before you install.

Do I need it with the fixed driver?+

No workaround is needed on the verified Adrenalin 26.11.2 / driver 32.0.32029.2010 build. Existing users can restore and uninstall the guard. Version labels alone do not extend that validation to other images.

Will it recover memory already leaked?+

It prevents the identified leak path from accumulating new allocations. It cannot reclaim memory already orphaned in the current Windows session. Normal AMD logs and shader caches continue to use disk.

Why might Windows warn about the publisher?+

The installer is self-signed. Windows may show an unknown-publisher warning. Follow the verification guide on GitHub before installing.

What if restoration reports a conflict?+

Keep the recovery files and follow the project’s recovery instructions, or contact support.
