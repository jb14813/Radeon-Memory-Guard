# Radeon Memory Guard website handoff

Upload `index.html` to `/apps/radeon-memory-guard/index.html` using the existing JZB Apps site assets. Use `app-card.html` for the Radeon entry on the homepage and apps listing.

The page marks Radeon Memory Guard as a legacy workaround, explains that the verified Adrenalin 26.11.2 build does not need it, and links to GitHub for the project and legacy downloads.
