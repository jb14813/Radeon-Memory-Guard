Radeon Memory Guard - Experimental
JZB Apps | https://jzbapps.com | support@jzbapps.com

Tested on Radeon RX 7900 XTX, AMD driver 32.0.32015.12012, and Windows 11 Pro 26H2 build 26300.

May cause instability, application crashes or loss of AMD features. Driver and Windows updates may break protection. Restore saved settings or uninstall if problems appear. Other GPUs, drivers and game features have not been comprehensively tested.

Complete setup enables background memory maintenance and redirects repeated executable-cache writes to a 64 MiB RAM disk. Custom setup offers memory maintenance only. AMD External Events Utility is briefly restarted when RAM protection is prepared.

A memory setting applied after driver loading may require a later driver reload or Windows restart. Setup does not restart either automatically.

The installer is self-signed. Windows may show an unknown-publisher warning. Signature and checksum verification instructions are available on the release page.

Uninstall restores saved settings and releases the RAM disk. Shared drivers and recovery records are preserved. See the included MIT license and third-party notices for license terms.
