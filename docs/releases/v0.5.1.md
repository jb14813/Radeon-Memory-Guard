# Radeon Memory Guard v0.5.1

**Published experimental prerelease · Windows x64 · JZB Apps**

Maintains the workaround for the identified Radeon process-watcher memory leak and optionally redirects one repeated AMD cache-write path to a 64 MiB RAM disk. The official AMD display-driver binaries are not modified.

## Compatibility and behavior

Requires administrator access, Windows PowerShell 5.1 and an official AMD Radeon driver. The measured configuration was **Radeon RX 7900 XTX, driver 32.0.32015.12012, Windows 11 Pro 26H2 build 26300**. Other GPU/driver combinations are not established by those tests. Eligibility checks require a signed AMD driver that exposes the setting; passing them does not prove effectiveness on an untested version.

- A hidden SYSTEM task runs at startup and every five minutes, maintaining **Gmx_MgpuProcessWatcherSupport=0** for an eligible active AMD display service. There is no tray icon.
- Complete Setup enables memory maintenance and RAM redirection. Custom Setup offers memory maintenance alone. RAM mode uses the bundled, signed Arsenal/AWEAlloc storage drivers; it does not install a third-party desktop mounting application.
- RAM mode redirects the SYSTEM-profile AMD **atieclxx.exe cache file**, not the AMD program executable. It uses 64 MiB of locked physical RAM plus driver/filesystem overhead. Preparing protection can briefly restart AMD External Events Utility; the service remains available afterward.
- The AMD retry loop continues. Ordinary logs, shader caches, guard state and recovery writes still use disk. This is not a promise to eliminate every SSD write or every Radeon memory leak.

## Installation, updates and recovery

Download and verify [RadeonMemoryGuard-Setup-0.5.1.exe](https://github.com/jb14813/Radeon-Memory-Guard/releases/download/v0.5.1/RadeonMemoryGuard-Setup-0.5.1.exe), then run it as administrator. Setup includes its RAM-backend payload. The [script ZIP](https://github.com/jb14813/Radeon-Memory-Guard/releases/download/v0.5.1/RadeonMemoryGuard-0.5.1.zip) is for manual/scripted use; installing its RAM backend can download the pinned driver package from GitHub.

Maintenance can repair the active setting and RAM link after compatible changes, but driver and Windows updates can break protection. Check Status after updates. A setting applied after driver loading may report **AppliedNeedsReload**, requiring a later driver reload or Windows restart. The guard does not trigger either automatically and cannot reclaim memory already leaked in the current session.

Run Setup again to repair. Windows uninstall restores saved settings/cache data and releases the owned RAM disk. Shared storage drivers and recovery records are preserved; conflicts may retain recovery tools/data rather than overwrite another change.

## Verification and measured limits

The installer/uninstaller use the JZB Apps self-signed identity, which does not establish public Windows trust or remove SmartScreen warnings. [Verification instructions](../../SIGNING.md) cover the public certificate, [SHA256SUMS](https://github.com/jb14813/Radeon-Memory-Guard/releases/download/v0.5.1/SHA256SUMS), its signature and verifier tools. Installer SHA-256:

    f99dd1f47433619707d09cde08e4e95fe683ab787fc24c77133e69d7cfa3ba43

The [release validation record](https://github.com/jb14813/Radeon-Memory-Guard/blob/v0.5.1/VALIDATION.md) documents bounded cache-write traces, 250 controlled process launches, graphics smoke tests and recovery checks. It does not validate full games/benchmarks, FreeSync/HDR, recording, sleep/resume, a real newer-driver installation, cold startup of this release or fresh-PC dependency installation. Instability, application crashes or loss of AMD features remain possible.
