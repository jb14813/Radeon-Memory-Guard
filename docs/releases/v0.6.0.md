# Radeon Memory Guard 0.6.0

**Legacy workaround.** The verified Adrenalin 26.11.2 / driver 32.0.32029.2010 build does not need the memory or RAM-cache workarounds. Prefer an official fixed driver; use this release only for an affected supported older build. Existing users on the verified fixed build can restore and uninstall.

Experimental Windows x64 utility for identified Radeon process-watcher memory and executable-cache write issues.

## Native fixes and compatibility

Version 0.6.0 recognizes the exact validated Adrenalin 26.11.2 images listed in [VALIDATION.md](../../VALIDATION.md). It restores its owned memory override to the saved original value and releases owned RAM redirection. The AMD service returns to its saved startup/running state. Native operation does not allocate the 64 MiB cache or install RAM-storage dependencies.

Native detection uses the driver hash and trust checks. SSD recognition additionally checks the service/client hashes. Version labels alone do not establish compatibility. Unrecognized images retain the previous compatibility behavior and are not reported as natively fixed. After a downgrade or unfamiliar update, check Status and rerun Setup if SSD protection is needed.

The recognition contract was tested on Radeon RX 7900 XTX and Windows 11 Pro 26H2 build 26300. With original settings and no RAM redirection, a bounded process-start trace retained no AMD allocations in the identified leak paths, and a separate native write trace showed no targeted cache writes. Other hardware, Windows versions, games and prolonged workloads remain unverified.

## Install and update

Download [Setup](https://github.com/jb14813/Radeon-Memory-Guard/releases/download/v0.6.0/RadeonMemoryGuard-Setup-0.6.0.exe), verify it using the release checksums and project certificate, and run it as administrator. The installer bundles dependencies needed by affected older drivers and requires no extra application framework. Updating an existing installation keeps recovery records.

A hidden SYSTEM task checks at startup and every five minutes. There is no tray icon or resident UI. The guard does not automatically reload devices or restart Windows. Registry changes can require a later reload to activate. It cannot reclaim memory already leaked by an older driver.

On affected drivers, optional RAM mode redirects the identified SYSTEM-profile cache. It does not suppress ordinary AMD logs, shader caches or other disk activity. Existing storage drivers are retained until normal uninstall/shared-use handling; native retirement releases the owned RAM volume.

## Recovery and risks

Setup and restoration may briefly interrupt AMD External Events Utility. Device reloads used for manual validation can terminate GPU applications. Instability, lost AMD features, blocked activation, and update conflicts remain possible. Conflicting files, settings or changed image identities are preserved for review.

Use **Restore and uninstall** to restore owned settings/cache data and remove the utility. Recovery records and shared components can remain. Do not delete recovery data while a restore conflict is unresolved.

The installer/uninstaller are JZB Apps self-signed; Windows/SmartScreen warnings can remain. See [SIGNING.md](../../SIGNING.md). No Windows trust/security-policy change is made.

## Privacy, license and support

State and recovery data remain local. There is no automatic diagnostic upload. Manual RAM-backend installation for affected drivers can fetch a pinned package from GitHub; Setup bundles it. AMD software has separate privacy settings.
